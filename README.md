## ✦ Overview

**thewoleisaiah** is a modern, high-performance portfolio website built for **Aluko Oluwole Isaiah**. Designed with a minimalist luxury aesthetic inspired by editorial typography, smooth micro-interactions, dark/light theme switching, and prominent personal branding across all pages.

---

## ✦ Key Pages & Structure

- **Home (`index.html`)**: Features the Techwitpro-inspired hero section with designer portrait glow, selected Behance case studies, services preview, and C.L.A.R.I.T.Y framework introduction.
- **About (`about.html`)**: The origin story, design philosophy, personal timeline, and core drivers.
- **Services (`services.html`)**: Comprehensive service breakdown (Brand Identity, Website Design, Mentorship, Ministry Branding, Content Systems) and direct collaboration pitch.
- **Work (`work.html`)**: Curated archive of client projects with live category filters, Behance links, and interactive case study lightboxes.
- **Framework (`framework.html`)**: Deep dive into the 7-stage proprietary **C.L.A.R.I.T.Y Framework** (Clarity, Legacy, Audience, Relevance, Identity, Traction, Yield).
- **Blog (`blog.html`)**: Strategic essays with real-time keyword search and author profile.
- **Contact (`contact.html`)**: Interactive Project Cost & Scope Estimator, direct 1-on-1 contact form, and meeting links.

---

## ✦ Features & Interactions

- **Prominent Designer Branding**: High-resolution portraits (`assets/wolee.jpg` and `assets/wole.jpg`) visible and styled across every page with status badges and cards.
- **Interactive Project Estimator**: Allows prospective clients to estimate scope and investment before inquiring.
- **Dynamic Case Study Modal**: Clickable work preview modals with project meta, deliverables, and external Behance links.
- **Dark / Light Theme Toggle**: Persistent mode preference saved in `localStorage`.
- **Micro-Animations & Smooth Reveal**: IntersectionObserver-based staggered scroll reveals and 3D card tilt effects.
- **Responsive Navigation**: Mobile slide-out drawer and desktop floating capsule nav.

## ✦ Pushing to GitHub

To push this repository to your GitHub account:

### Option 1: Double-click `push-to-github.bat`
Run the provided `push-to-github.bat` file in the project folder. It will guide you step-by-step.

### Option 2: Run in Terminal (PowerShell / Command Prompt)
```bash
# 1. Initialize git (if not already done)
git init

# 2. Add all files
git add .

# 3. Create your initial commit
git commit -m "feat: complete brand portfolio website with high-visibility portraits and interactive tools"

# 4. Rename default branch to main
git branch -M main

# 5. Link your GitHub repository (replace with your repository URL)
git remote add origin https://github.com/<YOUR_GITHUB_USERNAME>/<YOUR_REPOSITORY_NAME>.git

# 6. Push to GitHub
git push -u origin main
```
